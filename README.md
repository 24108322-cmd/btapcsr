# Portfolio cá nhân — Coursera Web Design Capstone

## Lựa chọn
**Tùy chọn 3: Demo danh mục đầu tư được thiết kế bằng khung (framework).**  
Dự án dùng Bootstrap 5 làm framework giao diện và CSS tùy chỉnh để tạo phong cách riêng.

## Chạy website
1. Giải nén thư mục.
2. Mở `index.html` bằng trình duyệt hoặc mở thư mục bằng VS Code và dùng Live Server.
3. Cần kết nối Internet để tải Bootstrap và Google Fonts từ CDN.

## Các tính năng bổ sung
1. Bố cục responsive cho màn hình lớn, máy tính bảng và điện thoại.
2. Nút chuyển đổi chế độ sáng/tối.
3. Bộ lọc dự án theo danh mục.
4. Biểu mẫu liên hệ có kiểm tra dữ liệu phía trình duyệt và thông báo trạng thái.
5. Liên kết bỏ qua điều hướng, nhãn biểu mẫu, trạng thái ARIA và hỗ trợ giảm chuyển động.

## Trước khi nộp
- Thay tên “Thuận” nếu cần và cập nhật nội dung cho đúng với bản thân.
- Đưa website lên GitHub Pages hoặc dịch vụ hosting rồi dán URL thật vào bài nộp.
- Chạy kiểm tra tại https://validator.w3.org/ và kiểm tra accessibility bằng WAVE hoặc axe.
- Chụp ảnh màn hình kết quả kiểm tra và giao diện website để làm bằng chứng. Không ghi rằng website đã đạt kiểm tra nếu chưa tự chạy công cụ.
